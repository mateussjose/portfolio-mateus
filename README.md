## 💻 Projeto

Este projeto é meu portfólio pessoal, desenvolvido para reunir e apresentar informações sobre minha trajetória acadêmica, conhecimentos técnicos, projetos e experiências na área de Tecnologia da Informação.

O portfólio foi desenvolvido como uma aplicação mobile utilizando React Native e Expo, com uma interface moderna, interativa e adaptada à navegação em dispositivos móveis.

A aplicação também conta com uma apresentação dos meus projetos e atividades, permitindo conhecer melhor minha evolução e experiência na área de desenvolvimento de software.

## 🚀 Tecnologias

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- React Native
- Expo
- Expo Router
- TypeScript
- JavaScript
- CSS
- Git e GitHub
- Visual Studio Code

## 🛠️ Funcionalidades

- Apresentação pessoal
- Formação acadêmica
- Habilidades e tecnologias
- Apresentação de projetos
- Experiências e atividades extracurriculares
- Elementos interativos e animações
- Jogo da Forca
- Navegação entre telas
- Interface adaptada para dispositivos móveis
